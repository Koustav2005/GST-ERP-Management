# External Material QR Code Collection Feature

## Overview
This feature enables workers to scan QR codes generated by Store Incharge to collect external job work materials. The flow consists of:

1. **Project Manager**: Creates material request for a worker
2. **Store Incharge**: Views request and generates QR code for worker to scan
3. **Worker**: Scans QR code to confirm material collection

### 4. Backend API Endpoints
**Location**: `backend/routes/external-jobwork-materials.js`

**New Endpoints**:

#### GET `/external-jobwork-materials/worker/:workerId/requests`
- Retrieves pending external material requests for a specific worker
- Authentication: Required
- Returns: Array of requests with items

**Response Structure**:
```json
{
  "requests": [
    {
      "id": 1,
      "project_id": 10,
      "worker_id": 5,
      "project_name": "Project Name",
      "worker_name": "Worker Name",
      "requested_by_name": "PM Name",
      "request_notes": "Optional notes",
      "status": "pending",
      "items": [
        {
          "material_name": "Steel Plate",
          "requested_quantity": 10,
          "unit": "kg"
        }
      ]
    }
  ]
}
```

#### POST `/external-jobwork-materials/requests/:requestId/collect`
- Worker collects external materials
- Authentication: Required
- Request body: `{ collected_by: workerId, collection_timestamp: ISO8601 }`
- Creates collection record and updates request status

**Response**:
```json
{
  "status": "success",
  "message": "Materials collected successfully",
  "collectionId": 123
}
```

## Technical Implementation

### QR Code Format
- Uses `react-native-qrcode-svg` library (already installed)
- QR size: 250x250 pixels
- Contains JSON payload with request metadata
- Backup manual code: REQ-{requestId}

### Camera Integration
- Uses `expo-camera` for QR scanning
- Graceful fallback if camera not available
- Manual code entry as fallback option
- Barcode scanner settings: QR codes only

### Database Considerations
- Creates `external_material_collections` table (backend)
- Updates `external_jobwork_outstock_requests` status to 'collected'
- Sends notifications to Store Incharge on collection
